# Missions

### Français

Onze missions, puis le boss. Tu ne sautes pas.

1. **Copier-coller** — {mod}+C puis V. On parle aussi de Couper (X).
2. **La machine à remonter le temps** — Annuler / Rétablir, Z / Shift+Z ou Y.
3. **Tout prendre** — Tout sélectionner, A.
4. **La pierre de sauvegarde** — Sauver, S. Pour ne pas perdre le dessin.
5. **Les onglets** — Nouvel onglet T, fermer W, onglet suivant.
6. **La loupe** — Trouver, F. La page est longue. Ça trouve le mot.
7. **Les yeux zoom** — {mod} + / − / 0.
8. **Changer de fenêtre** — Alt+Tab / Cmd+Tab. Quiz : l’ordi vole souvent les touches.
9. **Astuces de souris** — double-clic, clic droit, glisser. Quiz + pratique à l’écran.
10. **Capture** — photo d’écran (Win+Shift+S / Cmd+Shift+4 / Impr. écran). Quiz seulement.
11. **Sécurité express** — pas les pop-ups au hasard, pas le mot de passe à une page apparue toute seule, verrouiller (Win+L / Cmd+Ctrl+Q). Sérieux, pas effrayant.
12. **BOSS — Le Grand Mélange** — gauntlet chronométré, 10 items de toutes les missions.

{mod} = Ctrl sur Windows / Linux, Cmd sur Mac.

### English

Eleven missions, then the boss. You cannot skip.

1. **Copy-paste** — {mod}+C then V. Cut (X) is in there too.
2. **The time machine** — Undo / Redo, Z / Shift+Z or Y.
3. **Take it all** — Select all, A.
4. **The save stone** — Save, S. So you do not lose the drawing.
5. **The tabs** — New tab T, close W, next tab.
6. **The magnifier** — Find, F. The page is long. This finds the word.
7. **Zoom eyes** — {mod} + / − / 0.
8. **Switch window** — Alt+Tab / Cmd+Tab. Quiz: the computer often steals the keys.
9. **Mouse tricks** — double-click, right-click, drag. Quiz + on-screen practice.
10. **Screenshot** — screen photo (Win+Shift+S / Cmd+Shift+4 / Print Screen). Quiz only.
11. **Safety express** — no random pop-ups, no password to a page that just appeared, lock (Win+L / Cmd+Ctrl+Q). Kid-serious, not scary.
12. **BOSS — The Grand Mix** — timed gauntlet, 10 items from every mission.

{mod} = Ctrl on Windows / Linux, Cmd on a Mac.
